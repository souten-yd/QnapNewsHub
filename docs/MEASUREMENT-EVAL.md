# C6a 独立評価の実装（準備）

`cd backend && python -m tools.eval_measure GOLD.json PRED.json --ranking RANKING.json`
は原文の文字位置をキーに測定と条件の結合を別々に採点する。検索は重複を除いた R@10・MRR@10。
形式は tools/eval_measure/__main__.py の冒頭を参照。予測から正解を作らない。

実データは評価用の DB コピーから、分野・資料形式・条件の有無で層別抽出し、人が原文の span を確認する。
本文のない記事、複数測定、表の行列、負の値、同値別条件、機材の類似名、単位、推定値、条件不明を含める。
300 測定以上と 200〜300 問は目標。公開リポジトリに個人データや記事本文をコミットしない。

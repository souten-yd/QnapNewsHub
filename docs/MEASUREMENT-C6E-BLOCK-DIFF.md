# C6e document block difference candidates (Draft)

Read-only pure Python module. Splits saved Markdown-like raw text into heading, contiguous text (including contiguous Markdown table), fenced and unclosed fence blocks; original Unicode codepoint offsets, exact UTF-8 SHA256, heading chain. Compare only unique exact raw blocks; duplicates remain ambiguous. Adjacent block or heading changes mark context_changed. No fuzzy alignment, full Markdown AST, table row matching, semantic identity, or authority to reuse measurements. Blank-only changes still require full extraction. Non-local dependencies (footnotes, shared settings, subject lists, extraction version, policy and revisions) not proven; requires_full_extraction is true for any changed raw text. An unchanged raw text does not authorize reuse either: existing measurement_service input_hash/result_hash remain authoritative. Do not attach to writer or change DB, API, network, runtime, default or authorization.
